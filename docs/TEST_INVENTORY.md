## Asumsi yang Dibuat

1. **Library Customizer Desain adalah Fabric.js (bukan Konva)**:
   Meskipun instruksi prompt menyebutkan *"editor custom design Konva"*, hasil audit menyeluruh pada codebase membuktikan bahwa editor kanvas interaktif dibangun menggunakan **Fabric.js** (dikombinasikan dengan Cropper.js, Three.js preview, dan penyimpanan state JSON Fabric). Seluruh skenario uji modul Custom Design disesuaikan secara presisi dengan arsitektur Fabric.js yang ada.
2. **Ketiadaan Modul Voucher/Diskon dan Wishlist**:
   Di dalam kode rute (`routes/web.php`), migrasi database, dan controller tidak ditemukan kode yang menangani kupon/voucher diskon maupun wishlist. Oleh karena itu, skenario tidak dipaksakan ada, melainkan dicatat transparan di bagian fitur belum tersedia.
3. **Mekanisme Verifikasi Signature Webhook Paywuz**:
   Di dalam `app/Services/PaywuzService.php` baris 95–100, fungsi `verifyCallbackSignature($request)` saat ini masih mengembalikan nilai hardcoded `return true;`. Sebagai QA Senior, ini dicatat sebagai risiko keamanan kritis (Security Finding) yang wajib di-test secara negatif agar tim developer segera memasang validasi signature HMAC yang sesungguhnya.
4. **Alur Role & Panel Filament**:
   Terdapat 3 Panel Filament yang terisolasi dengan otorisasi berbasis Role Spatie:
   - Panel `/admin` khusus untuk role `Admin`.
   - Panel `/produksi` untuk role `Tim Produksi` dan `Admin`.
   - Panel `/owner` untuk role `Management/Owner` dan `Admin`.
   Pengguna dengan role Customer (Pelanggan) tidak memiliki hak akses ke panel-panel ini dan harus ditolak dengan HTTP 403.
5. **Kombinasi Pengujian Otomatis dan Manual**:
   - Logika bisnis (kalkulasi harga, diskon, surcharge, database record, IDOR, authorization, webhook) diuji menggunakan **PHPUnit** (Feature Test).
   - Validasi struktur respons API, JSON schema, dan parameter HTTP diuji menggunakan **Postman**.
   - Interaksi UI kanvas grafis (manipulasi layer, color picker kanvas, drag-and-drop logo, cropper) paling efektif diuji melalui **Manual** dan otomasi browser menggunakan **Laravel Dusk**.
